Аналіз онлайн-кампаній та підготовка даних GA4 для BI

Опис:
Цей проєкт демонструє аналіз ефективності рекламних кампаній Google та Facebook, а також підготовку даних Google Analytics 4 для подальшої інтерактивної візуалізації та розрахунку конверсій у BI-системах.

Інструменти:

DBeaver / PostgreSQL (для локальної бази ads_analysis_goit_course)

BigQuery (для GA4 eCommerce датасету)

Google Analytics 4 (для ознайомлення з даними)

Git (для зберігання SQL-файлів)

Структура проєкту:

Task_1_SQL/ – SQL-запити для аналізу рекламних кампаній (4 основні файли + 1 опціональний)

Task_2_BigQuery/ – посилання на збережені запити GA4 у BigQuery

Task_3_BigQuery/ – посилання на запити для розрахунку конверсій

README.md – опис проєкту та інструкції

Ключові завдання:

Аггрегація метрик по датах та платформах; топ-5 днів за ROMI; тижневі рекорди value; місячний приріст reach; (опційно) найдовша безперервна демонстрація adset.

Підготовка таблиці GA4 за 2021 рік для вибраних eCommerce подій.

Розрахунок конверсій funnel (session → cart → checkout → purchase) агреговано за датою та каналом трафіку.

(Опційно) Аналіз конверсії по landing page та кореляція engagement ↔ purchases.

Результат:

SQL-запити, що виконуються без помилок і видають очікувані результати.

Збережені BigQuery-запити з відкритим доступом.

Інструкції для запуску:

Клонувати репозиторій:

git clone <url_репозиторію>


Для Task 1: відкрити SQL-файли у DBeaver та виконати запити.

Для Task 2-3: відкрити посилання на BigQuery-запити та виконати їх для перегляду результатів.
